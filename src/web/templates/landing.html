Built so you can check it

    
An LLM is good at reading messy tables and trial text. It is not allowed to decide whether the analysis is sound. Code does that, with thresholds fixed before the data is looked at.

    
    
      
  • The LLM drafts. Code validates every column, code, horizon and covariate, and computes every gate and the verdict.
    • 
      
  • When a gate fails, the agent picks a fix from the failing numbers. It never sees the estimate, so it cannot chase a nicer result.
    • 
      
  • Every design version that reached the outcomes is listed in the report. Nothing is hidden, and the plan is hashed before any outcome is read.
    •

Two ways to run it

  

    

      
What you need

      

        
Inputs
The new trial as a CSV (treatment, time, event) and the historical study as a CSV. Column dictionaries are optional.

        
Optional
A ClinicalTrials.gov id or the eligibility text, so the historical patients can be filtered.

        
Time
One to five minutes, depending on the model backend.

        
Output
A report, a result file and a full audit log.

      

    

    

      

        

        
Single loop

        
Press start and get a report. The agent runs from the data to the verdict and repairs failed gates by itself.

        
  • Every question is answered “yes” automatically
  • The report says no human confirmed the steps
